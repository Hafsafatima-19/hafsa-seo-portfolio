HAFSA FATIMA — SEO PORTFOLIO
=============================

Files:
- index.html: portfolio homepage
- style.css: responsive design
- script.js: mobile navigation and current year
- assets/: supplied Google Search Console / Google Business Profile screenshots

Preview:
Open index.html in a browser.

Publish with GitHub Pages:
1. Create a new GitHub repository.
2. Upload all files and the assets folder (keep the folder structure).
3. In repository Settings > Pages, select Deploy from a branch.
4. Select the main branch and /(root), then Save.

Before making the portfolio public:
- Confirm you have permission to publicly display each client/business name and dashboard screenshot.
- Review the report dates and metrics for accuracy.
- Add a certificate only if you want it shown; it was not included in this version.
